# Chat Bot BFL

Статический чат-лендинг для первичной квалификации клиентов юридической компании «Есть решение».

## Что внутри

- `index.html` — основная страница чат-бота.
- `avito-chat.css` — стили чат-интерфейса.
- `avito-chat.js` — сценарий из 5 вопросов и контактная форма.
- `privacy.html` — политика обработки персональных данных.

## Публикация

Проект можно публиковать через GitHub Pages из ветки `main`, папка `/`.
